# Dreamforge -  övningsprojekt

## Syfte

Syftet med det här projektet är att jag vill lära mig om HTML och CSS. Eftersom jag även ska bygga Dreamforge's hemsida i Figma, var det ett bra case att använda i det här övningsprojektet. 
Till min hjälp har jag haft ChatGPT (6 Astra Medel). 

## Vad jag har övat på

Jag har övat på att skriva kod i html och i CSS. Jag har upptäckt att även mycket små saker gör stor skillnad. Missar man något, skriver fel eller använder fel tecken blir den slutliga produkten inte som man tänkt. 

I HTML har jag övat på rubriker, stycken och sidans struktur. Men header, mail, section och footer. I CSS har jag lärt mig hur man får olika färger, bakgrunder eller rundade hörn. Jag har även övat på CSS-variabler genom var(). För att få till en sida som även kan användas av de med olika funktionsnedsättningar så har sidan anpassats med synliga fokusramar, tangentbordsnavigering och förstoring. Jag har även övat i Git och GitHub med att granska ändringar, göra commits, läsa historik samt ladda upp projekt.
